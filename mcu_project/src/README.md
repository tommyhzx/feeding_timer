# 喂食计时器 - 功能说明

## 概述

这是一个基于 ESP32-S3 的双模式显示设备，支持时钟模式和计时器模式，使用 MAX7219 驱动的 8x32 LED 点阵显示屏。

## 硬件配置

| 组件 | 说明 |
|------|------|
| MCU | ESP32-S3-DevKitM-1 |
| 显示 | MAX7219 驱动 8x32 LED 点阵屏 |
| 按键 | 单个矩阵按键（GPIO7/GPIO4） |
| 网络 | Wi-Fi (NTP 时间同步) |

## 模式说明

### 时钟模式 (MODE_CLOCK)
- 显示通过 NTP 同步的网络时间
- 格式：HH:MM:SS
- 未同步时显示 `--`

### 计时器模式 (MODE_TIMER)
- 显示计时时间（时:分:秒）
- 支持开始、暂停、清零操作
- 切换到时钟模式时后台继续计时

## 按键操作

| 操作 | 功能 | 说明 |
|------|------|------|
| 长按 (≥1秒) | 切换模式 | 时钟模式 ↔ 计时器模式 |
| 短按 (<1秒) | 开始/暂停 | 计时器模式下控制计时 |
| 双击 (<300ms) | 清零 | 计时器模式下重置为 0 |

## 按键参数

| 参数 | 值 | 说明 |
|------|-----|------|
| 消抖时间 | 20ms | 防止机械抖动 |
| 长按阈值 | 1000ms | 判定为长按的时间 |
| 双击窗口 | 300ms | 两次点击的最大间隔 |

## 状态机

### 计时器状态 (TimerState)
```
IDLE ←→ RUNNING ←→ PAUSED
  ↓        ↓         ↓
 reset   start/pause pause
```

### 应用模式 (AppMode)
```
CLOCK ←→ TIMER
 (长按切换)
```

## 注意事项

1. **计时器保持**：切换到时钟模式时，计时器在后台继续运行，切回时恢复显示
2. **清零操作**：只有双击才会清零计时器，切换模式不会清零
3. **NTP 同步**：需要 Wi-Fi 连接才能显示正确时间
